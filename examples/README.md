## Rules every example follows
- Nothing PLANNED is stated as live: the Run 2 offer, the 7-day guarantee, month to month, and named supported job software all appear as `[OFFER PENDING]` or are left out.
- No proof points; `[PROOF POINT NEEDED]` where proof would sit.
- Every statistic carries its source in the sentence.
- Samples are labeled, with fictional shop and customer names.
