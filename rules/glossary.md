# Glossary, canonical vocabulary

Mirror these exactly in all copy. A term earns a row when getting it wrong would be visibly wrong to a buyer, or would turn a true claim into a false one.
last_reviewed: 2026-10-19

| Term | Rule |
|---|---|
| Rempo | One word, capital R. Never "REMPO" in prose. |
| Review Engine | The done-for-you review program, the front-end service. Two words, both capitalized. The live page calls the plan Starter. |
| GBP Tune-Up | One-time Google Business Profile optimization. Spell out "Google Business Profile" on first use in buyer copy; "your Google profile" after. |
| GBP Upkeep | Monthly posting to the profile and social from real jobs and reviews. Sold as staying current. |
| Review Engine Scorecard | The seven-question self-assessment. "The scorecard" after first use. |
| Google Review Gap Report | The free comparison with the local top three. "The Gap Report" after first use. |
| Personalized request | A request with the team's photo and the customer's first name. |
| Reply written for that review | How replies are described. Lead with what the reply does, not with "AI". |
| Job software | Buyer-facing word for the CRM or field-service software. Name a system (Jobber, Housecall Pro, ServiceTitan) only as the ledger allows. |
| Setup fee | Two words as a noun; "set up" as a verb. |
| Process guarantee | Internal name. Buyer form, when live: "First requests out within 7 days of your software connection, or your setup fee back." |
| Offer line | The sentence every buy button carries. PLANNED; see `feature-status.md`. |
| Location | The value metric. Each location is its own profile and request stream. |
| Owner, office manager | The buyer and the user. Not "decision maker" or "end user" in copy. |
| Home-service | Hyphenated as an adjective ("home-service shops"); "home services" as a noun. |
| Done for you | Three words; hyphenated only before a noun ("a done-for-you service"). |
| Hyperpersonalized | Banned. Say "personalized request". |
| Review generation, "get more reviews" | Banned. They name an outcome Rempo does not control. Say "review requests". |
| Reputation management (alone) | Banned without scope. Buyers hear review removal. Name what is included. |
| Autopilot | Banned. It implies the owner never does anything. Say "we run it for you" and list what they do once. |
| AI employee | Banned. Podium's category term. |
| Google Search Boost | Banned. The old name for the GBP Tune-Up. |
| Geotagging | Banned in sales assets. Dropped. |
| Free trial | Only with the setup fee beside it, while the trial is live. |
| Client vs customer | Client: the shop that pays Rempo. Customer: the client's customer, who is asked for a review. |
| Asked vs reviewed | Rempo asks every customer (a process it controls). Whether a customer reviews is theirs to decide. |

The distinction that matters most: **we ask every customer; we never promise a review.** "Every job asked, every review answered" is true because it describes what Rempo does. "More reviews" is a result Rempo does not control, and the moment copy slides from one to the other it breaks Google's rules and the FTC's.
