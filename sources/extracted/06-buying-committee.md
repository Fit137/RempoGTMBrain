## Sheet: Design_Partners

| Rempo go-to-market  ·  Buying Committee |
| Design Partners.  Skill phase: Phase 5.  Source: dashboards/05-buying-committee.md (Run 2, 2026-10-19). |
| Step 5.2. Design partner profile: the founding cohort |
| The first 5 to 10 paying shops. They supply the first baseline, the first measured results, and the first permission to cite. |
| Attribute | Specification |
| Design Partner Attributes | A busy HVAC or plumbing shop; the owner reachable by phone; jobs logged in Jobber or Housecall Pro; willing to compare personalized and plain requests inside the account |
| Job Titles | Owner; office manager |
| Demographics | 3 to 25 staff; 2 or more years trading; United States; 5 or more completed jobs a week |
| Responsibility Areas | Owner: marketing and spend. Office manager: the job software |
| Current Tools | Jobber, Housecall Pro, or ServiceTitan; the Google review link sent by hand, or a review switch turned on and left |
| Key Pain Points | The newest review is old; replies are missing; asking depends on memory |
| Critical Triggers | Slow season approaching; a bad review; a new competitor; starting Local Services Ads |
| Goals & Motivations | Less admin; a profile that matches the work |
| Decision Criteria | Effort required; price; whether requests and replies sound like the shop |
| Influence Level | Strong in local trade networks and Facebook groups |
| Barriers to Purchase | Setup fee before seeing anything; contract fear |
| Information Sources | Peers, trade groups, YouTube, their job-software marketplace |
| Success Metrics | Days to first request; ask coverage (every eligible job); reply coverage; reviews in the last 90 days against the baseline; request-to-review rate by request style |
| Early Adopter Characteristics | Answers their own phone; tries new tools; already pays for job software |
| Terms, set before the first signature: |
| •  What partners get: founding pricing or a waived setup fee ({TBD}), direct access to the founder, and influence on the product. |
| •  What partners give: a baseline at signup (Phase 0, Step 0.7), feedback calls in weeks 2 and 6, and consent to the personalized-against-plain comparison. |
| •  What partners are never asked for: a testimonial or a review of Rempo as a condition of the terms. Any testimonial is voluntary, used only in exact permitted wording, and discloses the founding relationship. Paying for reviews breaks the same FTC rule that governs Rempo's customers. |
