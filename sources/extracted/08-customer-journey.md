## Sheet: Insights

| Rempo go-to-market  ·  Customer Journey Funnel |
| Insights.  Skill phase: Phase 7.  Source: dashboards/07-customer-journey.md (Run 2, 2026-10-19). |
| Step 7.2. Key journey insights |
| Critical success factors |
| •  Days to first request: the guarantee makes this the number Rempo lives by. |
| •  The software connection: "after every job" is only true once job records reach Rempo. |
| •  The office manager's first week: nothing new for them to do. |
| •  A monthly report that makes the work visible, because done-for-you is invisible by design. |
| Primary journey blockers |
| •  Buyers without a CRM, who cannot get the done-for-you promise in full. |
| •  Texting registration eating into the first week. |
| •  Founder capacity for onboarding and sales calls beside a full-time job. |
| •  Level 2 buyers already paying for a tool, or under contract. |
| Acceleration opportunities |
| •  The scorecard as both the middle-of-funnel opt-in and the quarterly renewal touch. |
| •  A sample request sent to the buyer's own phone on the VSL page. |
| •  Field-service app marketplaces as a channel once connections exist. |
| •  The annual plan at month 3, with the setup fee credited. |
