# Template library

Shapes for every channel in the Rempo mix, and only those. Fill a template; do not invent a structure. Each one ends with its guardrails, because a template is where a hurried operator stops reading.

There is no cold email, LinkedIn, or cold texting template, because those channels are out of this GTM (`../rules/writing-rules.md`, channel discipline).

## How to use one
1. Load the router, the four `../rules/` files, and the reference file the template names.
2. Pick the audience in the template header. One per asset.
3. Pull lines from `../ops/copy-bank.md` before writing new ones.
4. Match the voice of the example the template names in `../examples/`.
5. Run `../ops/QA-checklist.md` before returning anything.

Delivery templates write copy that goes out under a client's name to that client's customers. They follow `../reference/review-compliance.md` before anything else.
