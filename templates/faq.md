# Template, FAQ

Audience: the owner. Also used as nurture email material and sales call prep.
Funnel stage: evaluation (step 3 of `../reference/customer-journey.md`).
Load first: `../reference/objection-handling.md`. Voice reference: `../examples/faq-answers.md`.

Answer each question in two to four sentences. Plain, honest, and specific. Where the answer is "not yet" or "it depends", say so.

## The questions (keep this order; add only from the signal log)
1. **Does it work with my job software?** Name a system only once `../rules/feature-status.md` lists it as confirmed. Until then: "We connect to the software you log jobs in. We confirm yours before you buy." Shops without one: the call.
2. **What do I have to do?** The four things, once: software connection, Google profile access, a team photo, texting details.
3. **What does the setup fee pay for?** The connection, the messages, the photo request, texting registration, and the first week of checks.
4. **When do requests start?** Email can start once the connection is made; texts once carrier registration clears (about a week, vendor estimate). The 7-day guarantee only if DECIDED.
5. **Can I cancel?** Only the terms that are live. Month to month is PLANNED; omit until DECIDED.
6. **Will texts annoy my customers?** One request and one reminder per completed job. Customers can opt out.
7. **Is this allowed by Google?** Yes, as Rempo runs it: every customer gets the same request, no rewards, no filtering, no asking to name staff. Link Google's policy.
8. **We already have reviews in Jobber.** The switch sends requests; nobody runs it. Rempo runs the program: requests, a reminder, a reply written for each review, a monthly report. Avoiding double requests: `{DEFERRED: product}`.
9. **Will you guarantee reviews or rankings?** No. We control asking and answering. How many customers review, and where Google ranks you, are not ours to promise. We track and report both.
10. **What don't you do?** Remove reviews, write reviews, filter unhappy customers, reward reviews.
11. **Why not NiceJob at $75?** NiceJob is a tool you run. Rempo is a service that runs. If you want to run it yourself, a tool is cheaper.
12. **I have three or more locations.** Book a call; priced per location.
